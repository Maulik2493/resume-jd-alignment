# Resume ↔ Job Description Alignment Engine

This project analyzes a resume against a job description to provide
**honest, constraint-based alignment feedback**.

## What This Tool Does
- Identifies improvements that can be made **without changing the truth**
- Separates wording improvements from **real experience gaps**
- Preserves the candidate’s original voice

## What This Tool Does NOT Do
- Invent experience
- Inflate claims
- Rewrite entire resumes
- Hide gaps with wording tricks

## Output Structure
- **Category A**: Content-level improvements (safe edits)
- **Category B**: Structural / experience gaps (not fixable by wording)
